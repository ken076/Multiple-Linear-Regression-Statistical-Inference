# Multiple-Linear-Regression-Statistical-Inference
## Multiple Linear Regression &amp; Statistical Inference  本專案使用 **R** 進行多元線性迴歸與統計推論，透過資料分析建立模型並探討應變數與多個解釋變數之間的關係。  專案涵蓋 **模型建立、參數估計、ANOVA、R² / Adjusted R²、假設檢定、信賴區間與預測區間**，從模型評估到預測結果的不確定性分析，完整實作統計建模流程。  透過本專案累積 **Statistical Modeling、Data Analysis 與 Statistical Inference** 的實務操作能力，並建立將統計方法應用於實際資料分析與問題解決的基礎。

資料介紹
Dataset Overview
• Usage in R: data(Gasoline)
• Dimensions: 25 rows (observations) × 12 columns (variables)
Variables List
• y: Miles per gallon (response variable)
• x1: Displacement (cubic inches)
• x2: Horsepower (foot-pounds)
• x3: Torque (foot-pounds)
• x4: Compression ratio
• x5: Rear axle ratio
• x6: Carburetor (barrels)
• x7: Number of transmission speeds
• x8: Overall length (inches)
• x9: Width (inches)
• x10: Weight (pounds)
• x11: Type of transmission (A = automatic, M = manual)
